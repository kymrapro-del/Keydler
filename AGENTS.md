# Repository conventions

- Write all source text, comments, documentation, labels, test names, fixtures and file names in English.
- Never use an em dash. Use a comma, colon, semicolon or full stop instead.
- In human-readable prose, put a space before a colon. Do not alter programming syntax, URLs or time notation to satisfy this rule.
- Attribute commits only to `moon1pact` with the GitHub private noreply address.
- Never add a `Co-authored-by` trailer.
- Commit complete, meaningful batches. Avoid bursts of tiny commits and leave a natural interval between commits.
- Run the full repository check before pushing.
