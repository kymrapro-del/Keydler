# Measurement logs

- [`tasks.md`](tasks.md) : the eight tasks, their ruled-out approach, its
  reason and the constraint that goes with it, plus the exact instructions for the
  two conditions.
- `results.md` : the records, added as the runs happen.

The protocol is described in
[`../protocols/measurement.md`](../protocols/measurement.md).

This directory holds only real records, never a fabricated example. A run that
goes badly appears here on the same footing as any other.
